# Audio To Code Generator - Public Demo & Code Inspection 🎮🎧

Public sample demo scene and pre-generated C# audio scripts for **Audio To Code Generator (Indie Edition)** for Unity.

---

### 💡 What is this repository?
This repository allows Unity developers to inspect and test pre-generated C# audio bytecode directly in a Unity project before purchasing. 

You can check the code structure in `/BasicUsage/` to verify:
* **Clean Code Architecture:** Pure C# scripts with zero external runtime DLL dependencies.
* **Optimized Compression:** Lightweight Gzip + Base64 bytecode decompression with minimal memory footprint.
* **Zero Audio Files:** Audios play directly via code without loose `.wav` or `.mp3` files in your project.

---

### 🚀 How to Test the Demo in Unity:
1. Clone or download this repository as a `.zip` file.
2. Put the `BasicUsage` folder into your Unity project's `Assets` directory (Unity 2022.3 LTS+).
3. Open `BasicAudioDemoScene.unity` and press **Play**.
4. Test the sound triggers and inspect the inspector controller!
